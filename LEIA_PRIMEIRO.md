# Das trevas para a luz — pacote independente

Comece pelo arquivo **GUIA_PUBLICACAO_GRATUITA.md**.

Este pacote contém o código-fonte preparado para GitHub, Cloudflare Workers e Cloudflare D1. A versão externa protege o painel do professor com senha administrativa configurada como segredo na Cloudflare. Nenhuma senha real está incluída neste arquivo.

Antes de publicar, você precisará criar o banco D1 e informar o `D1_DATABASE_ID`, conforme o guia.
